### Hey, I'm Siddid.

Systems engineer & builder based in Kathmandu, Nepal. Focused on low-level systems architectures, hardware-software co-design, non-blocking concurrency, and high-performance vector indexing. Currently building **[Shaligram Labs](https://github.com/qvost/shaligram-labs)**.

---

### What I'm Exploring

- **Linux Kernel & Runtime Systems**: Scheduler mechanics (EEVDF), zero-copy asynchronous I/O (`io_uring`), SLUB hardening, and eBPF observability.
- **Lock-Free Concurrency**: Safe memory reclamation (Hazard Pointers, Epoch-Based Reclamation), atomic memory barriers, and false-sharing-free ring buffers.
- **High-Dimensional Vector Search**: Product quantization (PQ / IVF-PQ), asymmetric distance computation, and SIMD acceleration (AVX-512, ARM NEON).
- **Modern Edge & Local-First**: Deterministic state machines, zero-cost abstractions in Rust, and local-first data architecture.
